# NOC Dashboard — iMaster NCE

A network operations monitoring dashboard inspired by Huawei iMaster NCE/NOC environments.

## Overview

The dashboard provides a visual representation of network infrastructure status, including operational network layers, alarms, service health, and monitoring information.

## Features

- NOC-style monitoring interface
- Core, Metro and Aggregation network visibility
- Network operational status indicators
- Alarm/status monitoring
- Responsive dashboard interface
- Frontend/backend-ready architecture

## Technologies

- HTML5
- CSS3
- JavaScript
- Go
- REST API concepts
- Network monitoring concepts
